プライバシーポリシー

当アプリは、利用者のプライバシーを尊重し、 利用者に関する情報を適切に取り扱うため、以下のとおりプライバシーポリシー（以下、「本ポリシー」といいます）を定めます。

利用者は、当アプリを利用するにあたり、本ポリシーの内容を確認し、同意したうえで利用するものとします。

1. 取得する情報

当アプリでは、サービスの提供、維持、改善のため、以下の情報を取得する場合があります。

1.1 アカウントに関する情報

  • メールアドレス
  • Firebase Authentication等の認証サービスにより発行されるユーザーID
  • ログイン方法に関する情報
  • ニックネーム、プロフィール画像またはアバター画像
  • 言語設定、通知設定、その他アプリ内設定

1.2 投稿・投票・操作に関する情報

  • 相談のタイトル、本文、カテゴリ、選択肢などの投稿内容
  • 投稿に添付される画像
  • 投票・回答内容、回答日時
  • お気に入り、通報、非表示などの操作情報
  • 通報理由、通報対象、通報日時など、通報対応に必要な情報

1.3 購入・サブスクリプションに関する情報

  • App Storeのアプリ内課金に関する取引ID、商品ID、購入日時、有効期限、更新状態など
  • プレミアム会員状態の確認・管理に必要な情報

クレジットカード番号等の決済情報は、Apple Inc.により処理され、当アプリが直接取得することはありません。

1.4 お問い合わせに関する情報

  • お問い合わせフォームに入力されたメールアドレス、問い合わせ内容、発生状況、使用端末に関する情報
  • 当アプリからの問い合わせ対応に必要なやり取りの内容

1.5 端末情報・利用状況・診断情報

  • 端末の種類、OSバージョン、アプリバージョンなどの情報
  • クラッシュログ、エラーログ、パフォーマンスに関する情報
  • 不正利用防止やセキュリティ保護のための検証情報
  • 広告配信のために必要となる端末識別子等の情報
  • IPアドレス、およびIPアドレス等から推定される国・地域に関する情報

2. 情報の取得方法

当アプリは、以下の方法により利用者に関する情報を取得します。

  • 利用者が当アプリ上で入力、投稿、送信する方法
  • 利用者が投票、お気に入り、通報、設定変更などの操作を行う方法
  • Firebase Authentication、App Store、Google AdMob、Firebase Crashlytics等の外部サービスを通じて取得する方法
  • お問い合わせフォームまたはメール等により利用者から提供される方法
  • 当アプリの利用時に、端末やアプリから自動的に送信される方法

3. 利用目的

取得した情報は、以下の目的で利用します。

  • ログイン、本人確認、アカウント管理のため
  • 投稿、投票、お気に入り、通報、翻訳、プレミアム機能など、当アプリの機能を提供するため
  • 投稿内容や投票結果の表示、集計、分析のため
  • 不適切な投稿の確認、削除、表示制限、利用制限など、安全なコミュニティ運営のため
  • お問い合わせへの対応、重要なお知らせの送信のため
  • サブスクリプションの購入確認、有効期限管理、不正購入防止、返金・解約等への対応のため
  • 不具合調査、品質改善、利用状況の把握、機能改善のため
  • 不正利用、スパム、規約違反、セキュリティ上の問題の防止および調査のため
  • 広告の表示、広告配信の管理のため
  • 法令、規約、Appleその他プラットフォームの要件に対応するため
  • 利用者の国・地域を推定し、投稿・投票結果の集計、表示、分析、サービス改善に利用するため

4. ユーザー生成コンテンツの公開範囲

当アプリでは、利用者が投稿した相談、選択肢、画像、投票結果、ニックネーム、アバター画像等が、 当アプリ内で他の利用者に表示される場合があります。 個人を特定できる情報や公開を望まない情報を投稿しないようご注意ください。

通報内容やお問い合わせ内容は、原則として一般の利用者には公開されません。 ただし、通報対応、不正利用調査、法令対応、利用者または第三者の権利保護のために必要な範囲で確認・利用する場合があります。

5. 外部サービスの利用

当アプリでは、サービス提供に必要な範囲で以下の外部サービスを利用する場合があります。 各サービスにおける情報の取扱いは、各事業者のプライバシーポリシー等に従います。

  • Firebase Authentication（Google LLC）：ログイン・認証
  • Cloud Firestore / Cloud Functions for Firebase / Firebase Storage（Google LLC）：データ保存、サーバー処理、画像保存
  • Firebase App Check（Google LLC）：不正利用防止
  • Firebase Crashlytics（Google LLC）：クラッシュ解析
  • Google AdMob（Google LLC）：広告配信
  • App Store / StoreKit / App Store Server Notifications（Apple Inc.）：アプリ内課金、サブスクリプション管理
  • OpenAI API（OpenAI, L.L.C.）：投稿内容や投票結果に関するAI分析・要約機能
  • Googleフォーム（Google LLC）：お問い合わせ受付
  • IPinfo（IDB LLC）：IPアドレスに基づく国・地域情報の推定

翻訳機能、AI分析機能、広告配信機能、国・地域情報の推定機能などの提供に必要な範囲で、 投稿内容、投票結果、IPアドレス、端末情報等が外部サービスに送信される場合があります。

Googleプライバシーポリシー： https://policies.google.com/privacy
OpenAI Privacy Policy： https://openai.com/policies/privacy-policy
Apple Privacy Policy： https://www.apple.com/legal/privacy/

6. 広告について

当アプリでは、広告配信のためにGoogle AdMobを利用する場合があります。 広告配信のため、Google LLCが端末識別子、広告識別子、利用状況等の情報を取得する場合があります。

当アプリは、メールアドレスや当アプリ内のユーザーIDを、利用者を他社のアプリやWebサイトをまたいで追跡する目的で広告事業者へ提供することはありません。 将来、パーソナライズ広告やトラッキングに該当する機能を導入する場合は、必要に応じて利用者への通知または同意取得を行います。

7. 第三者提供および委託

当アプリは、以下の場合を除き、利用者の同意なく個人情報を第三者に提供しません。

  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要な場合
  • 公的機関から正当な手続により開示を求められた場合
  • 利用者または第三者の権利、利益、安全を保護するために必要な場合
  • サービス提供、決済、広告配信、クラッシュ解析、お問い合わせ対応等に必要な範囲で外部サービス事業者または業務委託先に提供する場合
  • 事業の譲渡、承継、合併その他これらに類する手続に伴い、必要な範囲で提供する場合

外部サービス事業者または業務委託先に情報を取り扱わせる場合、当アプリは、利用目的の達成に必要な範囲で情報を取り扱わせるものとします。

8. 共同利用について

当アプリは、現時点において、取得した個人情報を他の事業者と共同利用することはありません。 今後、共同利用を行う場合は、法令に従い、共同利用する情報の項目、共同利用者の範囲、利用目的、管理責任者等を公表します。

9. 情報の管理およびセキュリティ

当アプリは、取得した情報について、漏えい、滅失、毀損、不正アクセス、改ざん等を防止するため、合理的な安全管理措置を講じます。 また、認証、アクセス制御、通信の暗号化、App Check等の仕組みを用いて、不正利用の防止に努めます。

10. 情報の保存期間および削除

取得した情報は、利用目的の達成に必要な期間保存します。 退会またはアカウント削除が行われた場合、アカウント情報は削除または匿名化されます。

ただし、法令遵守、不正利用防止、料金・購入管理、通報対応、問い合わせ対応、サービスの整合性維持その他運営上必要な範囲で、 投稿、回答、通報、購入履歴等の一部情報を一定期間保存する場合があります。

11. アカウント削除

利用者は、当アプリ内の設定画面からアカウント削除または退会手続きを行うことができます。 アカウント削除により、ログインに必要な認証情報およびアプリ内アカウント情報は削除または匿名化されます。

App Storeのサブスクリプションを利用している場合、アカウント削除を行っても、App Store上のサブスクリプションが自動的に解約されない場合があります。 サブスクリプションの解約は、Apple IDのサブスクリプション管理画面から行ってください。

12. 外部リンクに関する注意事項

当アプリまたは関連ページには、外部事業者のWebサイトやフォームへのリンクが含まれる場合があります。 リンク先における個人情報の取扱いについては、各リンク先のプライバシーポリシー等をご確認ください。 当アプリは、リンク先の内容または個人情報の取扱いについて責任を負いません。

13. 未成年者の利用

当アプリは、13歳未満の方による利用を意図していません。 未成年の方が利用する場合は、保護者の同意を得たうえで利用してください。

14. 開示・訂正・削除・利用停止等の請求

利用者は、当アプリが保有する自己の情報について、開示、訂正、削除、利用停止等を求めることができます。 ご希望の場合は、本ポリシー末尾の連絡先までお問い合わせください。 請求内容によっては、本人確認をお願いする場合があります。

法令またはサービス運営上の理由により、請求の全部または一部に応じられない場合があります。 その場合は、可能な範囲で理由を説明します。

15. プライバシーポリシーの変更

当アプリは、法令の変更、サービス内容の変更、利用する外部サービスの変更等に応じて、本ポリシーを変更することがあります。 重要な変更がある場合は、当アプリ内または本ページ上でお知らせします。 変更後のプライバシーポリシーは、本ページに掲載された時点から効力を生じるものとします。

16. お問い合わせ先

本ポリシーに関するお問い合わせは、当アプリ内またはApp Storeに掲載されているサポート窓口よりご連絡ください。
